# PriAurity

Website, privacy policy and support for PriAurity, a Mac menu bar app that keeps your
preferred audio input and output devices selected.

- Site: https://makeable.github.io/priaurity/
- Support: https://makeable.github.io/priaurity/support/
- Privacy policy: https://makeable.github.io/priaurity/privacy/

To report a problem, [open an issue](https://github.com/makeable/priaurity/issues/new).
